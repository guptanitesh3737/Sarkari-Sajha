# SarkariSajha - UI/UX Design System & Theme Guidelines

## Typography & Visual Palette
- **Primary Canvas**: Clean off-white / light slate (`bg-slate-50`) paired with high-contrast slate text (`text-slate-900`).
- **Brand Accents**:
  - **Government / Trust**: Deep Emerald Green (`emerald-800` / `emerald-600`) and Crimson Red (`rose-700` for Nepal government accents).
  - **Match Highlights**: Amber/Gold (`amber-500`) for top AI match highlights.
  - **Data Visualization**: Recharts custom color bars (Green ≥80% match, Blue standard scale, Indigo banking).

## Component Guidelines
- **Responsive Layout**: Desktop-first design scaled mobile-first via Tailwind (`sm:`, `md:`, `lg:`).
- **Control Sizing**: Touch targets ≥44px on mobile views.
- **Empty & Loading States**: Clean skeletal pulse animations during network/API operations.
- **Micro-interactions**: Subtle motion feedback, hover states, and clear badge indicators.
